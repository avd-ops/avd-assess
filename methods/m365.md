# Microsoft 365 and collaboration method

How to judge the Microsoft 365 Apps, OneDrive, Teams, and browser multimedia settings that run inside Azure Virtual Desktop sessions. It is the [assessment](assessment.md) method applied to the Microsoft 365 control plane (`m365`), linking the images (`images`) and remote protocol (`protocol`) pillars to the Intune and tenant policy surfaces that configure them (`gap:m365-scope`).

## Method

1. **Ask whether the estate runs Microsoft 365 Apps, OneDrive, and Teams inside AVD sessions** (`intake.m365PlaneScope`) before judging collaboration policies (`gap:intake`, `gap:m365-scope`).
2. **Check Microsoft 365 Apps shared computer activation** on pooled multi-session hosts so multiple users can activate Microsoft 365 Apps on the same session host without consuming personal activation slots (`ref:avd-office-image#shared-computer-activation`, `ref:review-checklists-avd#B01.09`, `gap:m365-scope`).
3. **Check OneDrive per-machine installation, Files On-Demand, and Known Folder Move** so user folders redirect silently to OneDrive without bloating the FSLogix profile container with full local copies (`ref:avd-office-image#onedrive-per-machine`, `ref:onedrive-vdi#files-on-demand-vdi`, `ref:onedrive-vdi#silent-config-and-kfm`, `ref:onedrive-vdi#per-machine-install`, `gap:m365-scope`).
4. **Check Microsoft Teams media optimization for VDI** (SlimCore / WebRTC media redirection and `IsWVDEnvironment`) so audio, video, and screen sharing offload to the local client endpoint instead of rendering on the session host CPU (`ref:teams-on-avd#media-optimization`, `ref:teams-on-avd#classic-teams-end`, `ref:review-checklists-avd#B01.10`, `ref:review-checklists-avd#B03.02`, `gap:m365-scope`).
5. **Check browser multimedia redirection (MMR) and WebRTC redirection policies** where users watch browser video or use web-based calling inside sessions (`ref:avd-multimedia-redirection#mmr-browser-video`, `ref:review-checklists-avd#B03.02`, `gap:m365-scope`).
6. **Check update channel and new Outlook readiness** so M365 Apps updates follow the servicing model for the host pool rather than fighting image rollouts (`ref:avd-office-image#line-of-business-after`, `ref:avd-update-methods#multisession-image-based`, `gap:m365-scope`).
7. **Score M365 checks as not applicable** when `intake.m365PlaneScope` is `"not-used"`, and leave checks `unknown` when the `m365` plane was not collected (`gap:m365-scope`, `gap:scoring`).

## Not yet known

- How often estates deliver Shared Computer Activation and OneDrive Known Folder Move through the golden image registry or Group Policy instead of Intune settings catalog profiles (`gap:m365-scope`).
